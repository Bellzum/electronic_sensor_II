# Circuit Design Tools (alternatives to Tinkercad)

Tinkercad is great for learning but has a limited parts list. These tools offer more components.

| Tool | Cost | Has RC522? | Simulates code? | Best for |
|---|---|---|---|---|
| **[Cirkit Designer](https://www.cirkitdesigner.com)** | Free (web + desktop) | ✅ | Partly | Closest to Tinkercad: drag-and-drop breadboard wiring with a large module library |
| **[Wokwi](https://wokwi.com)** | Free (web) | ❌ | ✅ Very good | Running and debugging Arduino, ESP32 or Pi Pico code |
| **[Fritzing](https://fritzing.org)** | ~€8 (desktop) | ✅ | ❌ | Neat breadboard figures for reports |
| **[EasyEDA](https://easyeda.com)** | Free (web) | ✅ | Basic | Learning proper schematics, PCBs later |
| **SimulIDE** | Free (desktop) | ❌ | ✅ | Offline simulation of Arduino and basic electronics |
| **[Falstad CircuitJS](https://www.falstad.com/circuit/)** | Free (web) | ❌ | ✅ | Learning how voltage and current behave (resistors, LEDs, transistors) |

## Recommended order
1. **Cirkit Designer**: practise wiring this RFID project by hand.
2. **Wokwi**: test code without the real hardware.
3. **EasyEDA**: learn schematic symbols for later robot dog breadboard modules.
